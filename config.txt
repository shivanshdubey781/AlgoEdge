============================================
 BOT CUSTOMIZATION INSTRUCTIONS (READ FIRST)
============================================

Use this guide to change SL, TP, RSI values, Strike Step, etc.

Each section clearly tells:
- WHICH FUNCTION
- WHICH LINE NUMBER
- WHAT TO CHANGE
- WHY IT AFFECTS TRADES


=====================================================
1️⃣  CHANGE TARGET (TP) & STOPLOSS (SL)
=====================================================

➡ LOCATION IN CODE:
Inside function: monitor_trade()
Go to approximately: LINE 840 – LINE 860

➡ EXACT LINES TO EDIT:

For CE:
    target_price = entry_ltp + TARGET_POINTS
    sl_price     = entry_ltp - STOPLOSS_POINTS

For PE:
    target_price = entry_ltp - TARGET_POINTS
    sl_price     = entry_ltp + STOPLOSS_POINTS

➡ WHAT TO CHANGE:
- Change TARGET_POINTS to adjust TP
- Change STOPLOSS_POINTS to adjust SL

Example:
    TARGET_POINTS = 30
    STOPLOSS_POINTS = 10


=====================================================
2️⃣  CHANGE RSI LEVELS (RSI → CE / PE)
=====================================================

➡ LOCATION IN CODE:
Inside function: generate_signal()
Go to approximately: LINE 780 – LINE 820

➡ EXACT LINES TO EDIT:

For CE signal:
    if rsi <= 30 and astro == "upside":
        return "BUY CE"

For PE signal:
    if rsi >= 70 and astro == "downside":
        return "BUY PE"

➡ WHAT TO CHANGE:
- Change 30 for CE trigger
- Change 70 for PE trigger

Example:
    RSI_CE = 25
    RSI_PE = 80


=====================================================

=====================================================

➡ LOCATION IN CODE:
